# Hritik Suman — Portfolio

Live at: **[hritiksum.github.io/portfolio](https://hritiksum.github.io/portfolio/)**

## Pages

| File | Page |
|------|------|
| `index.html` | Home — hero, career overview, featured projects, blog preview |
| `about.html` | About — bio, stats, skills, certifications, recommendations |
| `experience.html` | Experience — full work history with correct dates |
| `projects.html` | Projects — filterable grid (ML / Backend / Mobile) |
| `blog.html` | Blog — Dev.to articles |
| `contact.html` | Contact — links + contact form |
| `style.css` | Shared styles for all pages |

## Deploy to GitHub Pages

1. Push all files to the `portfolio` repo on GitHub
2. **Settings → Pages → Source → Deploy from branch**
3. Branch: `main` · Folder: `/ (root)` → Save
4. Live in ~60 seconds at `hritiksum.github.io/portfolio/`

## Customizing

| What to update | Where |
|----------------|-------|
| 3rd LinkedIn recommendation | `about.html` — find `reco-card` with placeholder text |
| Add blog post | `blog.html` and `index.html` — copy a `blog-card` block |
| Profile photo | Add `<img src="img/profile.jpg">` in `about.html` |
| Contact form (live) | Replace Formspree URL in `contact.html` with your Formspree endpoint |
| Accent color | Edit `--accent` in `style.css` |
| Add new experience | Copy a `company-block` in `experience.html` |
